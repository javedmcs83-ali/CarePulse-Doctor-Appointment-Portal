🩺 CarePulse — Doctor Appointment Booking Portal
Clinic Operations · Microsoft Power Platform Project
A Power Apps Canvas application on Microsoft Dataverse that digitizes clinic appointment booking from first call to consultation. Receptionists, Doctors and Clinic Admins each land on their own screen at launch, bookings and consultation notes live in one place, and a Power Automate flow emails the patient a branded booking card the moment an appointment is created.
Power Apps Canvas App Microsoft Dataverse Power Automate Role-Based Start Screen HTML Confirmation Email Solutions
Why This Was Built
🎯 Problem Statement
❌
Scattered booking records: Appointments were noted down from calls and walk-ins in separate sheets, with no single source of truth for who is booked with which doctor and when
❌
One view for everyone: Reception, doctors and clinic admins all needed different things from the same data, but had no role-specific screens
❌
No written confirmation: Patients had nothing in writing showing their date, time slot, doctor and appointment ID
❌
Doctor details out of reach: Specialty, OPD room and consultation fee were not available in the same place where bookings were made

Core Design Pattern
🔐 Role-Based Start Screen Routing
⚙️
How the app decides where each user starts
Power Apps · Dataverse
1
Find the user's role
A named formula in App.Formulas looks up the signed-in user's email in Tbl_User_Roles, comparing Lower() on both sides, and returns the User Role
→
2
Pick the screen
App.StartScreen runs a Switch() on that role value
→
3
Land on the role's screen
Receptionist opens Patient Bookings, Doctor opens Doctor Consultation, Clinic Admin opens Clinic Admin
App · Formulas
Var_Logged_User_Role = LookUp(
    Tbl_User_Roles,
    Lower('User Email Address') = Lower(User().Email)
).'User Role';
App · StartScreen
Switch(Var_Logged_User_Role,
    "Receptionist", Scr_Patient_Bookings,
    "Doctor", Scr_Doctor_Consulation,
    "Clinic Admin", Scr_Clinic_Admin
)
Tbl_User_Roles — one row per user, mapping an email address to Clinic Admin, Doctor or Receptionist
